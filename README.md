# 思虑过多者 vs 行动者（代码复刻）

用纯 Three.js 复刻抖音「火柴人跳水」隐喻短片：**不使用任何视频生成模型**。

## 打开方式

```bash
cd /workspace/stickman-dive
python3 -m http.server 8093
```

浏览器打开：http://127.0.0.1:8093/

竖屏 9:16 画布，会按窗口等比缩放。

## 操作

- **R**：重新播放时间轴
- 约 14 秒循环：左侧「思虑过多者 / OVERTHINKER」在跳板上犹豫、踱步、托腮；右侧「行动者 / DOER」反复起跳落入水面，溅起涟漪后回到跳板再跳。

## 技术

- Three.js r160（本地 vendor）
- UnrealBloomPass 轻微辉光
- 反射地面用镜像克隆（非 AI）

## 说明

仅复刻故事画面，不含抖音水印与片尾分享卡。
